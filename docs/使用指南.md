# 示例资源库使用指南

[返回首页](https://github.com/aiml1025/my-new-app)

适用于本体 0.3.0、网页助手 0.1.2。**本资源库是供体验与参考的示例，不保证本版本的数据在后续版本中继续可用，也不承诺迁移。** 先用少量测试资料熟悉操作，并保留重要原文件及备份。

## 先分清三样东西

| 名称 | 存的是什么 | 举例 |
| --- | --- | --- |
| 资料条目 | 你录入的信息及关联 | 影片标题、演员、标签、来源网页 |
| 本地资源库 | 由软件管理的文件目录和文件索引 | 视频文件所在的普通资源库 |
| 封面库 | 专门存放封面图片的资源库 | 条目的横向、纵向封面 |

资料可以先建立，文件以后再补。文件也不会因为在硬盘上存在，就自动变成一条完整资料。

## 建立或加载资源库

### 第一次使用

1. 启动桌面本体，打开侧栏的“资源库”。
2. 选择“创建资源库”，填写名称并选择存储目录。建议先选新建的空目录，方便区分测试文件。
3. 需要保存封面时，在顶部封面库位置创建封面库。当前可设置一个封面库，普通资源库可以有多个。
4. 后续导入影片时，选择已加载、可用的普通资源库；封面库不作为视频导入目标。

资源库配置会保存，下次启动时恢复加载。磁盘或目录不可用时，不会把那里的文件显示成可用本地副本。

### 已经有本软件创建的资源库

选择“导入资源库”，定位到已有库的根目录，加载其索引。该操作保留原目录和文件。

**这不是普通文件夹的自动识别入口。** 目录需要有当前格式的资源库索引（`FileIndex.db`）；旧格式 `library.db` 不能直接当成当前资源库导入。单独加载文件索引也不会恢复影片、演员等资料关系，完整备份还需要应用数据目录。

## 导入视频并建立关联

### 从文件开始

1. 在桌面端打开支持视频导入的具体影片列表，例如“日本有码”或“日本无码”。
2. 将文件拖到列表，打开带有待导入文件的新建表单。
3. 填写条目资料。默认保留文件名并选择可用普通资源库；通过文件项的“编辑导入设置”检查和调整。
4. 核对资源库、相对目录、命名及预览的目标路径，再提交表单。
5. 查看导入进度和结果。条目创建与文件导入分步完成，看到条目不代表文件已经导入成功。

### 给已有条目补文件

打开条目的“视频文件”字段，选择或拖入文件，检查导入设置后提交。一次多选的文件可以归入同一组，适合一部影片有多个分段的情况；可以调整组内顺序。

### 文件会被复制，还是移动？

通常会将源文件**移动**到选定资源库的目标路径。操作前看清预览路径，不要把导入理解成仅添加快捷方式。

- 来源已被本软件索引时，会复用已有文件。
- 来源尚未索引，但已在某个已加载的本地资源库目录内时，可以选择“保留原路径”，只登记索引而不移动。
- 来源在资源库外时，不能使用“保留原路径”。

当前影片导入按扩展名支持 `mp4`、`avi`、`mov`、`wmv`、`mkv`。不支持的文件混在同一次选择中会被拒绝，先分开处理。

资源库管理、视频文件选择和拖入、打开文件位置及本机播放属于桌面能力，浏览器页面不能完整替代这些操作。当前本地播放会调用本机程序，不提供完整的浏览器串流影院。

## 网页助手安装与排查

### 安装

1. 从 [0.3.0 Release](https://github.com/aiml1025/my-new-app/releases/tag/v0.3.0) 下载 `web-enhancement-shell-0.1.2.zip`。
2. 解压到长期保留的固定目录。加载后不要删除这个目录。
3. 打开 `chrome://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，选中包含 `manifest.json` 的目录。Edge 对应入口是 `edge://extensions`，相关开关以实际浏览器为准。
4. 在扩展详情中开启“允许用户脚本”。当前构建目标为 Chrome 138 及以上。
5. 启动桌面本体，点击插件图标，在“本体连接”中连接实际本机地址。默认是 `http://127.0.0.1:3001`，端口不同则改为实际地址。

当前使用可解压加载的 ZIP，不提供站外 CRX 安装包。Chrome、Edge 的商店签名证明限制可能使 CRX 报 `CRX_REQUIRED_PROOF_MISSING`，重新压缩文件不能解决。

### 从一个网页开始收录

1. 打开已适配的资料页，点击插件图标。
2. 已有对应本地条目时，选择“关联已有”，确认搜索范围和关键词后搜索，再选中条目关联；没有条目时，选择“创建新条目”。
3. 关联完成后，可在网页内浮层或新标签页编辑资料；有适用爬虫时，可以开始采集。
4. 采集成功后打开“刮取确认”，核对已有信息，选择关联或新建相关条目。**采集成功只说明取得候选资料，不表示全部信息已经写进正式条目。**

网页增强会在已有适配的列表页展示关联状态及操作入口，不是所有网站和所有页面都有增强。当前主要示例是 JavDB 详情资料及演员作品列表，详情采集不包含自动下载影片、磁链或封面。

### 更新插件

下载 Release 指定的插件 ZIP，覆盖原目录文件，在扩展管理页重新加载，然后刷新已打开的网页。若提示离线，点击插件里的“重新连接”。

本体更新不会替你更新手动加载的插件。两个版本号各自独立，按 Release 的配套要求使用；0.3.0 对应网页助手 0.1.2。

### 常见情况

| 现象 | 先检查什么 |
| --- | --- |
| 插件显示离线或 `!` | 本体是否运行、连接地址是否正确；本体恢复后点“重新连接”，不要只等自动重试 |
| 能关联条目，但网页增强或采集报错 | 扩展详情是否开启“允许用户脚本”，网页是否有适配 |
| 提示版本不匹配 | 按提示更新本体或插件，重新加载插件并连接 |
| 浏览器能看，本体后台采集失败 | 后台使用独立浏览环境，不自动沿用日常浏览器登录；检查网站设置里的 Cookie、代理和访问条件 |
| 当前网页采集中断 | 是否刷新、跳转或关闭了来源标签页；关闭插件弹窗本身不等于关闭来源页 |
| 列表按钮发起的采集遇到验证页 | 列表的采集操作由本体后台执行，和插件弹窗里的当前网页采集不同 |
| 已关联却没有视频可播放 | 关联指网页与资料条目的关系；还需有可用的本地视频文件 |
| 采集结束但资料没有全部补齐 | 打开“刮取确认”核对处理；当前适配也不覆盖网页上的所有信息 |
| 当前页图片拖不进网页内浮层 | 浏览器有同页跨域拖放限制，可改在新标签页打开表单，或从另一个标签页拖入 |
| 同样的操作以前可用，现在失败 | 网站页面结构、登录验证、权限或网络可能改变；反馈时附来源网址、错误提示和采集方式 |

工具栏关联与表单入口不依赖用户脚本 API；当前网页采集和列表增强需要该权限。站点规则和适配脚本由本体下发，许多适配更新只需更新本体，但插件自身能力或兼容要求变化时仍须更新插件。

## 浏览器访问与同步

在桌面打开一条资料，点击工具栏“在默认浏览器中打开”。这会使用本体实际监听的地址，比手动猜端口更可靠。

本机常见地址示例：

```text
http://127.0.0.1:3001/class/Jav
```

这是影片列表的示例地址，端口以实际运行值为准。只打开根地址 `/` 会看到服务提示，不是完整应用首页。条目地址还包含身份参数，建议直接用应用打开的地址，不手工拼接。

若要在另一台设备的浏览器查看，把实际地址中的 `127.0.0.1` 替换成运行本体电脑的局域网 IP，保持端口、路径和参数不变。两台设备需能互相访问，主机防火墙也需允许连接。

本体必须保持运行。当前没有公网账号认证和细粒度访问权限，请限于可信环境，不把端口直接开放到公网。插件目前按本机地址连接，不能把跨设备浏览器访问步骤套用到插件设置中。

**实时同步的是已提交的数据及共享视图配置。** 各页面未提交的输入、创建草稿和打开位置各自独立，不会自动搬到另一个标签页。网页浮层最小化会保留原实例；在新标签页打开则是新的页面。

筛选也有单独的使用边界：已显示记录会更新，排序字段变化会重排；修改已有记录的字段或关联后，若要重新计算哪些记录应出现，点筛选面板中的“刷新”。多个关联路径条件分别匹配，不保证由同一个关联对象同时满足。

## 更新备份与卸载

### 更新

安装版启动后后台检查、下载更新，也可在“设置与帮助”中手动检查。下载完成后由你选择重启安装。差量更新可减少下载量，条件不满足时使用完整安装包。

正常安装版更新会保留数据目录，但**未来版本的数据可读性和迁移不作保证**。请在升级前备份，并阅读对应 Release 的具体说明。

### 完整备份

1. 从“设置与帮助 → 设置 → 打开数据目录”找到 `%APPDATA%\my-new-app-test`。
2. 从托盘退出程序，等待退出完成。
3. 备份整个应用数据目录。
4. 另外备份自己选择的外部普通资源库和封面库目录，包括其中的索引及文件。

应用目录包含资料数据库、配置和采集缓存；外部资源库包含实际文件。只备份其中一边，不能当作完整备份。备份用于保留当前状态，也不意味着新版本一定支持读取旧数据。

### 旧 ZIP 版

旧 ZIP 版与安装版的数据目录结构不同，不直接复用旧数据。先退出旧程序，备份需要保留的内容，再按安装说明清理旧 `%APPDATA%\my-new-app-test` 目录后安装。

已使用 0.1.1 或更高版本安装版的用户，不要套用这项旧 ZIP 清理操作；正常升级从应用内进行，具体兼容要求看对应 Release。

### 卸载

卸载默认保留用户数据。若勾选“删除用户配置和全部本地数据”，会永久清理应用数据根目录中的配置、数据库、采集缓存及日志，以及 `%LOCALAPPDATA%\my-new-app-test-updater` 更新缓存。卸载页会显示实际路径，请确认后再选。

自行选择的外部媒体目录保留；浏览器插件需要在浏览器扩展管理中另行移除。若卸载提示文件占用或权限错误，不能据此认为已经清理完成。
